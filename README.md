# GSK – Web Stock Management

Welcome to **GSK (Stock Management Web)**, a modern and intuitive web application for stock management and sales tracking, developed as part of my final cycle project in L1 LMD FASI at UPC.

---

## ✨ Overview

GSK is a simple and effective solution for:

- **Managing your stock items** (add, edit, delete, quick search)
- **Tracking daily sales** with automatic summary
- **Viewing and exporting** your data (PDF/Excel, upcoming features)
- **Responsive interface** with dark blue theme for optimal comfort

## 🚀 Main Features

- **Add, edit and delete items**
- **Dynamic search** by item name
- **Sales management** (confirmation, tracking, automatic total calculation)
- **Daily sales summary**
- **PDF/Excel export**
- **Responsive design** (mobile/tablet/desktop compatible)
- **Professional dark theme**

---

## 📦 Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/CoffeePuma55644/projet-web-gestion-de-stocks.git
   ```

2. **Open the application:**
   - Open `index.html` in your web browser
   - Or use a local server for optimal performance

3. **Start using:**
   - Add your first items to the stock
   - Manage sales and track your daily revenue
   - Export your data when needed
